# 密码重置蕴含邮箱验证

**Status**: 已废弃（superseded by ADR-0002）——邮箱验证功能已整体移除，`verifiedAt` 字段不再存在，本决策失去作用对象。

账号可能处于"已注册但未验证邮箱"的状态，此时用户忘记密码。我们决定：密码重置成功的同时将邮箱标记为 verified。因为能收到重置邮件本身就证明了邮箱所有权——这与点击验证链接证明的是同一件事；若重置后仍要求单独验证，用户改完密码依然登录不了，闭环出现裂缝。

**Considered Options**: 重置只改密码、验证状态不变（被拒：制造"改了密码却进不了门"的死锁体验，且安全上并无增益）。

**Consequences**: `resetPassword` 会写 `verifiedAt`，读代码时不要误以为是笔误而"修复"掉。
